# Bartleby Debugger

A CLI debugger that would prefer not to.

> [!NOTE]
> This is a parody of [nietzschian-debugger](https://github.com/DilawarShafiq/nietzschian-debugger). There is no package, no CLI, and no code. Bartleby would prefer not to ship any.

![Bartleby, preferring not to](prefer-not-to.gif)

## Why

Other AI tools fix your bugs. This one declines to, mildly and politely, and keeps on declining.

## Install

```bash
pip install bartleby-debugger  # it would prefer not to install
```

## Usage

```bash
bartleby debug "login returns 403"
```

## Intensity levels

- **scrivener** (default): prefers not to.
- **dead letter office**: prefers not to, and stares at a wall while it does.
- **the tombs**: prefers not to eat, either.

## Session commands

- `solved`: Bartleby says nothing.
- `I give up`: Bartleby says nothing.
- `exit`: Bartleby stays in your terminal anyway.
